# 建築法規研讀入口

公開網站：https://swentsan.github.io/building-technical-rules/

四個入口：圖解、分析、技規、基隆市法規。技規查詢位於 `technical.html`，舊的條文分享網址會自動轉往對應條文。公開版及 NAS 版均使用整理好的基隆地方法規查詢頁。

基隆查詢頁位於 `keelung.html`，保留 73 項預設法規、版本核對、條文差異、240 份附件及 84 項人工檢核。條文圖解提供全部 1,182 條的對應圖，共 3,147 組（包含刪除狀態圖）；另保留 12 組精選漫畫。

以條文為入口，同步呈現按編別與條號分類的相關函釋彙編、歷年修正原頁及新舊版本比對。

- 四編官方封存全文：1,182 條。
- 函釋彙編對應：250 條、284 組分類。
- 五冊原始掃描 PDF：2,280 頁，保留原 PDF 頁碼及 SHA-256。
- 公開版提供查詢、版本比較及更新草稿 JSON 匯出；正式資料由管理者更新共用 SQLite 資料庫後再發布。

`docs/` 為 GitHub Pages 發布內容，`src/` 為介面原始碼，`data/technical-corpus.json` 為同一資料庫產生的技術規則模組資料。

掃描 OCR 及分類不等於法律效力認定；請核對原 PDF、官方公布與施行日期。本站為資料整理工具。
